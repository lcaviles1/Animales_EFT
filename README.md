# Unidos por los Animales - EFT Semana 9

Proyecto desarrollado con Spring Boot, Spring Security, Thymeleaf, MySQL y JUnit.

## Estructura
- frontend
- backend
- mysql

## Requisitos
- Java 21
- Maven Wrapper
- Docker Desktop
- MySQL en contenedor

## Ejecución
### Backend
cd backend
./mvnw spring-boot:run

### Frontend
cd frontend
./mvnw spring-boot:run

## URLs
- Frontend: http://localhost:8081
- Backend: http://localhost:8080
